About

The objective of this Bridge is to encourage and showcase the combination of Constraint Programming (CP) and Machine Learning (ML). “Constraint Programming” is taken broadly to encompass all approaches to constraint satisfaction and optimization. “Machine Learning” is taken broadly to include symbolic and neural approaches.

Topics

Relevant topics include but are not limited to:

  • Acquiring constraints
  • Learning heuristics
  • Performance optimization through tuning
  • Algorithm selection
  • Learning constraint models
  • Using LLMs/Chatbots to solve constraint satisfaction problems
  • Using CP to address ML limitations
  • ML for combinatorial optimization
  • Learning preferences
  • Explanation/reformulation of statistical models with constraints
  • Embedding constraint reasoning in ML
  • Combining prediction and optimization
  • CP for fairness in ML
  • Synthesizing CP models from natural language

Format

This will be a 2-day Bridge, with a half day held jointly with the AAAI-27 tutorial on LLMs for Constraint Modeling, for which CPML Bridge registrants are encouraged to register as well. The Bridge will include talks, posters, a panel/discussion and a hackathon.

Attendance

Attendance is open to all. Submission of posters is encouraged. Registration is through AAAI-27.

Call for posters

Submissions are sought in the form of posters. Posters are intended to encourage interaction and start conversations. They should contain basic information on the poster authors, their interests, and contact info. In addition, they must feature one of the following:

  • work in progress
  • prior published work
  • a demo
  • an application or tool
  • an evaluation or comparison
  • an agent or app
  • a community resource (code, benchmarks, survey, tutorial, bibliography, …)
  • a proposal (for a collaboration, special issue, workshop, competition, …)
  • a “grand challenge” or “research roadmap”

Posters should be accessible to a broad audience from both the CP and ML community.
